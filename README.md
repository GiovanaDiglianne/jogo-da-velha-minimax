# Agente para o Jogo da Velha (Minimax)
Implementação de um agente que recebe o estado do tabuleiro e retorna a jogada ótima usando o algoritmo Minimax, com poda alfa-beta. O agente é ser capaz de jogar contra um humano ou contra outro agente, por meio de uma interface simples via terminal. Utiliza Minimax e poda alfa-beta.
